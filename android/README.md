# 申论随拍 Android

原生 Kotlin + Jetpack Compose / Material 3 应用，只提供真题选题、系统相机或相册导入、视觉模型 OCR、文字校对和电脑端草稿录入。兼容 Android 10+（minSdk 29），compile/target SDK 36；可在 Android 17 的兼容机制下运行，支持系统取色、深浅色、全面屏和系统返回手势。未在用户的 Android 17 / 骁龙865实机上做帧率或续航压测。

## 使用

1. 电脑更新至 v0.1.28 或以上，并开启局域网访问。
2. 电脑左侧选择「手机拍照录入」，生成六位配对码。
3. 手机上安装 Release 中的 `shenlun-companion.apk`，填写 Mac 的局域网 IP 地址（例如 `http://192.168.1.20:18086`）和配对码。两端连接同一局域网。电脑设置的管理密码不需要填入手机。
4. 在手机「连接与 OCR」单独配置支持图片输入的视觉模型：支持 OpenAI 兼容、Anthropic Claude 和 Gemini 原生协议。根地址、模型 ID、API Key 必须来自同一家服务商；模型需支持图像输入。该配置独立于电脑端批改模型。
5. 选择试卷和题目，拍照或导入照片，每次最多6页。可预览、旋转、前移排序及移除；多页按列表顺序一次识别。
6. 核对文字和 □ 难辨字后同步。电脑打开对应题目的练习页：空草稿自动接收；已有内容时选择追加、替换或忽略。替换前保留本地备份，可恢复。题干/材料在发送后变更时不自动录入，先核对同步时的题干。

照片直接发给手机配置的 OCR 服务商，不发给电脑；电脑只接收校对文字。OCR 请求不携带试卷材料、参考答案或评分标准，不自动批改、润色或补写。识别效果取决于字迹、光照和视觉模型，需要人工校对。

手机按电脑实例及题目保存照片和文字草稿；同一电脑IP变更后重新配对，仍可在原题恢复草稿；密钥及配对 token 使用 Android Keystore AES-GCM 加密存储，禁用云备份和设备迁移；电脑保存持久录入记录，重复点击/超时重试使用相同请求编号，不重复插入。手机可从电脑设备列表撤销授权。手机 token 仅用于题目目录与录入，无法操作模型设置、批改或画像。

## 轻量与性能

- 原生 Compose 与惰性列表，默认跟随系统取色和深浅色；不嵌入整个电脑网页，不运行本地大模型。
- 系统相机、系统照片选择器，无需申请广泛存储权限；照片复制、缩放、旋转和网络序列化均在后台执行。
- 照片解码先降采样，上传最长边2048、JPEG质量86，去除原始EXIF；逐页处理，单图3MB、批次16MB base64保护上限。小尺寸缩略图独立加载，不在列表中解码完整原图。
- 每次识别一次调用处理多页；仅明确不支持输出参数时兼容重发一次，共用原等待预算。默认8192输出tokens、600秒等待，可调至1024–32768及60–1800秒。
- 正式包启用 R8、资源裁剪和合并基线配置，约2.4MB。没有广告、统计或后台常驻轮询服务。识别期间保持页面，取消或失败会保留原照片与文字。

## 构建与签名

需要 JDK 17+、Android SDK 36、build-tools 36.0.0。Gradle Wrapper 为8.11.1，附官方分发校验值。

```bash
cd android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleRelease
```

CI 验证无私钥构建及测试；正式APK使用独立私有签名。拥有者本地创建 `signing.properties`（已忽略）：

```properties
storeFile=.signing/release.p12
storePassword=填写本地私有口令
keyAlias=shenlun-release
keyPassword=填写本地私有口令
```

签名文件、口令和 `local.properties` 不进入Git或Docker上下文。**请由拥有者备份 `.signing/release.p12` 与签名配置；未来升级必须使用同一私钥，否则安卓不允许覆盖安装并保留应用数据。** 当前正式签名证书 SHA-256：`976b51b942e05ee8783ee517f915373f9b9b6da4c4a723af397f0485a98a4285`。

验证包括 OCR 三协议请求与响应、输出参数兼容、错误脱敏、按题同步、原生Compose界面及图片EXIF/尺寸处理。Compose/图片测试使用 Robolectric Android 15（API35），不能替代Android17或骁龙865实机验证。真实付费 OCR 接口没有使用用户密钥进行测试。
