# 中文稿纸排版与占格（v2）

参考 W3C《中文排版需求》：[行首行尾禁则](https://www.w3.org/TR/clreq/#prohibition_rules_for_line_start_end)、[符号分离禁则](https://www.w3.org/TR/clreq/#prohibition_rules_for_unbreakable_marks)。其标点章节以《标点符号用法》GB/T 15834—2011 等为基础。查阅日期：2026-11-03。

这些资料规范中文排版，不规定浙江申论所有考场的稿纸容量、数字占格或字数评分。软件将通用标点原则转为以下训练规则；数字两位一格是明确采用的训练约定，不冒充全国考试统一强制规则。

| 内容 | 软件处理 |
| --- | --- |
| 汉字 | 一字一个完整方格，不是两格；全角字与两个半角字符的宽度不要混淆 |
| 半角数字和英文 | 连续串两字符一格，奇数尾字符占一格；1. 同格，2026 两格，12.5% 三格；短串不足本行余格时整体移至下行，超长串按格续写 |
| 常见句末标点、后引号、右括号 | 自动行满时与末字同格，避免标点被甩至下一行开头；连续后引号也保留在末格 |
| 前引号、左括号、前书名号 | 不单独留在最后一格，留白后与后续正文进入下行 |
| ——、…… | 成对占两格，余格不足两格时整体换行 |
| 换行、缩进 | 保留实际输入；每次换行耗用本行余格，段首空两格和落款对齐均占格；不会擅自改写用户的分段 |
| 字数 | 非空白字符仍逐个统计，含标题、称呼、落款；纸面合格和字数统计独立，不能靠数字合格绕过字数上限 |

同一套规则用于前端编辑、参考范文预览、后端占格检查和模型提示。答题纸仍然是每行25格、300字12行等原有容量。旧版带纸面快照的练习沿用原规则；原答案不会被自动改写。
